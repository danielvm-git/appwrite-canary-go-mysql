# e02s01 — Harness page

**As** an operator **I want** a page that drives the API from the browser **so
that** the MySQL path can be checked without curl.

## Acceptance
- `web/` signs in with Appwrite Auth and calls the Function for every data action.
- No database driver or credential in the browser.
- `web/config.example.js` documents endpoint, project id and function id.
- Known limitation: this is a harness, not the shared shell UI.
