# e01s01 — Schema and migration

**As** an operator **I want** the Todo schema in MySQL **so that** the API has a
relational home instead of Appwrite TablesDB.

## Acceptance
- `internal/schema/sql/001_init.sql` (embedded in the binary) creates `lists`, `tasks`, `task_shares` with the
  indexes the requirements name (`by_user_status`, `by_list`, `title_search`).
- `POST /admin/migrate` (token-protected) applies them from inside the function;
  CI calls it after every deploy. No SSH, no client on the VPS.
- Collaborators live in `task_shares`; the API re-materialises `sharedWith` /
  `sharedNames` on every read so the UI contract is unchanged.
- Row `seq` (auto increment) is exposed as `$sequence` for the `#N` label.
