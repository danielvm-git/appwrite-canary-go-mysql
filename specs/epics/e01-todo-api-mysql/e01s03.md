# e01s03 — Share by e-mail

**As** a task owner **I want** to share by e-mail **so that** the invitee can read
and move the task.

## Acceptance
- The seven cases from the requirements pass (`internal/share/service_test.go`):
  grant + name, empty ACL, anonymous, invalid e-mail without DB call, non-owner,
  missing row, and `no_user` / `self` / `already`.
- Invitee resolved through the Appwrite Users API with `users.read`.
- E-mail normalised (trim + lowercase); `a@b` rejected.
