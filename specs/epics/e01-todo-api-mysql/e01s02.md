# e01s02 — API and permissions

**As** a canary user **I want** owner/collaborator rules enforced server-side
**so that** the Appwrite permission gap (raw PATCH touching other columns) closes.

## Acceptance
- Routes: `GET/POST /tasks`, `GET/PATCH/DELETE /tasks/{id}`, `GET/POST /lists`,
  `DELETE /lists/{id}`, `POST /share`, `GET /health`.
- Anonymous → 401 with code `unauthorized`.
- Owner: full update, delete.
- Collaborator: read, and `PATCH` limited to `status`; anything else → 403 `forbidden`.
- Stranger: 403 on read.
- Validation: empty title, unknown status/priority → 400 `invalid`.
